### 食い違いの修正

旧 CLAUDE.md の「稼働中の観測は --no-reset (ただし open だけでリセットが
かかるアダプタもある)」を、P1 実機受け入れの実測で置き換えた:
**Tab5 は open だけで必ずリブートする** (rst:0x17、--no-reset でも不可避)。
「稼働中を横から覗く」は Tab5 では不可能で、開きっぱなし運用が唯一の
観測手段。reset: false の方がバナーから採れる (S3 は従来どおり)。
