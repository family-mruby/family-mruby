# fm_sig_editor

`fmruby-core/sig/*.rbs` の doc コメントを編集するデスクトップアプリ。
エディタが補完のときに出す 1 行要約と、F1 で開く長文ヘルプが対象。
Ruby + glimmer-dsl-libui で書かれていて、WSL2 では WSLg にそのまま窓が出る。

```
gem install glimmer-dsl-libui                   # 初回のみ (sudo 不要)
ruby tools/fm_sig_editor/fm_sig_editor.rb       # fmruby-core/sig を開く
ruby tools/fm_sig_editor/fm_sig_editor.rb PATH  # 別の sig ディレクトリ
```

## なぜ専用の道具か

doc コメントには、書いているときに見えない上限が 2 つある。

- **要約は 111 バイトで黙って切れる**。エディタが固定長の箱に写すため
  (`ET_DOC_MAX` は 112 で、最後の 1 バイトは終端)。しかも要約は
  `日本語 <<en>> English` と 2 言語を 1 行に載せるので、英語を足した時点で
  越えやすい。切れても何も言わないので、書いた人は気づかない。
- **長文ヘルプの表示幅は約 39 桁**。散文はどこで折り返しても読めるが、
  コードブロックは語の途中で折れる。長いパスを例に書くと
  `/usr/share/sprites/flapp` `y/bird.bmp` と割れる。

この道具は、要約のバイト数を打ちながら出し、越えていたら保存を断る。
長文の中でコードブロックに入っていて幅を越えている行は一覧に出す。

## 画面

- 左: そのファイルの doc コメントを持つメンバーの一覧。
  Bytes 列が要約のバイト数 (越えていれば OVER)、Long 列は長文があるか。
- 右: 選んだメンバーのシグネチャ (読み取り専用) と、要約 ja / en、
  長文 ja / en の 4 つの入力欄。
- 下: Save (書き戻す)、Revert (選び直す)、rake ti:help (`flash/help` を
  作り直す。長文を直したら実際に F1 で出るのはこれを走らせた後)。

上の Filter にメソッド名の一部を入れると一覧を絞れる。

## 触らないもの

**シグネチャと、コメント以外の行は 1 バイトも動かさない**。書き戻すのは
選んだメンバーの doc コメントの行範囲だけで、読み取りは RBS の
パーサ (型 db と `rake ti:help` が使うのと同じもの) を通す。つまり
「エディタがどのメンバーの説明として出すか」がこの道具の表示と一致する。

`sig/README.md` にある約束のうち、**シグネチャの形と 1 行要約の書き方**は
この道具では守れない (文章の中身までは見ない)。書き方はそちらを読むこと。

## 確かめ方

```
ruby tools/fm_sig_editor/test/round_trip_test.rb
```

sig/ の全ファイルの全コメントを読んで、何も変えずに書き戻し、**バイト単位で
元と同じ**であることを確かめる。あわせて、1 件だけ編集して保存したときに、
その行範囲だけが変わり、前後の行が動かず、RBS で読み直せることも見る。
